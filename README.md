Сайт, подключенный к базе данный PostgreSQL. Добавлена JWT аутентификация, сделаны регистрация/вход. Информация о товарах, их описание и характеристики беруться из базы данных. Данные пользователей при регистрации заносятся в базу данных, пароли хэшируются.
Сделана обработка форм обратной связи: заявка на демонстрацию продукта, обращение по каким либо вопросам, Форма обратной связи для отзывов. Данные, занесенные в формы обрабатываются и сохраняются в БД.
Оставить отзыв можеть только авторизированный пользователь! Заказать демонстрацию и написать обращение - любой желающий.
Сделаны базовые проверки на корректность вводимых пользователем данных. 
Сессия пользователя запоминается.
Сервер - Apache. Был скачан xampp, папка проекта перемещена в папку htdocs. 
Доступ к сайту осуществляется по ссылке http://localhost/web3/index.php.
